# Version Bump Checklist

The project version must be updated in **5 files** simultaneously. Missing any one causes inconsistent version display.

## Quick bump

```bash
node scripts/bump-version.js X.Y.Z
```

Example: `node scripts/bump-version.js 2.3.1`

## Manual checklist

| File | Key | Example |
|------|-----|---------|
| `package.json` | `"version"` | `"version": "2.3.1"` |
| `src-tauri/tauri.conf.json` | `"version"` | `"version": "2.3.1"` |
| `src-tauri/Cargo.toml` | `package.version` | `version = "2.3.1"` |
| `src/config/version.ts` | `APP_VERSION` | `export const APP_VERSION = "v2.3.1"` |
| `README.md` | shields.io badge | `version-2.3.1-blue` |

## Notes

- `package-lock.json` is auto-generated by npm and does **not** need manual update.
- The Rust binary embeds `Cargo.toml`'s version at compile time; the frontend displays `version.ts`'s value at runtime.
- `tauri.conf.json` is used by the Tauri bundler for installer metadata.

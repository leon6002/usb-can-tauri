# Mock ZCU 模拟工具使用说明

`mock_zcu.py` 是一个轻量级的 Python 脚本，主要用于在没有真实 ZCU (Zone Control Unit) 硬件设备时，在 PC 本地或树莓派等局域网设备上模拟真实的以太网 UDP 硬件交互。配合 OSYX 车辆控制软件使用。

## 1. 脚本原理
该脚本会在本地持续监听 5000 端口获取传入的 UDP 数据，剥离读取原数据的 JSON 请求负载，并秒回一条符合协议约定的带 JSON 格式的 `ACK` 确认报文到发送端的 5001 端口。

## 2. 基础配置
使用前，您可能需要打开该脚本修改顶部的两行配置：
```python
# 模拟 ZCU 的监听地址
ZCU_IP = "0.0.0.0"   # 修改为 0.0.0.0 以允许局域网其他机器(如PC)连接；如果是 127.0.0.1 则只允许本机测试
ZCU_PORT = 5000      # 数据包接收端口

# 上位机(OSYX 软件)的接收端口
PC_PORT = 5001       # 数据回传目标端口
```

## 3. 运行指南

### 场景 A：纯本地单机自环测试 (PC -> PC)
1. 确保已安装 Python 环境（版本 3.x）。
2. （可选）修改 `mock_zcu.py` 中的 `ZCU_IP = "127.0.0.1"`（为了安全，不让外部网段接入）。
3. 在脚本所在目录打开终端，运行命令：
   ```bash
   python mock_zcu.py
   ```
4. 终端会提示：`[*] Mock ZCU 正在监听 ...`
5. 回到 OSYX 软件 UDP 面板：
   - **Local Port** 填 `5001`，点击 "Start Listen"
   - **Target IP** 填 `127.0.0.1`，点击 "Transmit" 发包。

### 场景 B：跨设备局域网仿真测试 (PC -> 树莓派 / 其他主机)
1. 将 `mock_zcu.py` 脚本复制到树莓派中。
2. **必需操作**：用文本编辑器打开树莓派中的脚本，确保 `ZCU_IP = "0.0.0.0"`，否则无法接收外部网络的请求。
3. 获取树莓派此时在局域网中的 IP 地址（例如 `192.168.1.33` 或直连固定的 `192.168.1.100`）。
4. 在树莓派系统终端运行：
   ```bash
   python3 mock_zcu.py
   ```
5. 回到 PC 上的 OSYX 软件 UDP 面板：
   - **Local Port** 填 `5001`，点击 "Start Listen"
   - **Target IP** 填入步骤3获取的树莓派的实际 IP（如 `192.168.1.33`），点击 "Transmit" 发包。

## 4. 日志解读
脚本运行后，每次接收到上位机请求并成功处理后，会在终端打印两次信息：

1. **收到 PC 请求**：打印出发起请求的来源 IP、端口以及收到的原始 Payload 负载。
   ```text
   [收到 PC 请求来自 ('192.168.1.5', 63412)]:
   {"header":{"seq":1001,"timestamp":1772712057,"source":"PC_HOST"}...
   ```
2. **发送 ACK 应答**：打印回填序列号 `orig_seq` 的组装后 JSON，确认已经向指定的 `PC_PORT` （5001）发射了报文。
   ```text
   [发送 ACK 应答至 ('192.168.1.5', 5001)]: {"header": ... "msg": "这是一个模拟的应答"}}}
   ```

> 如果需要终止模拟，直接在终端中按下 `Ctrl + C` 即可。
